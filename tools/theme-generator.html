사용 방법
1. 이미지 또는 PPTX 파일을 업로드하면 색상이 자동 추출됩니다.
2. 각 색상의 역할(배경, 제목 등)을 클릭해서 조정할 수 있습니다.
3. 테마 이름 입력 후 CSS 생성 → .css 다운로드.
4. 다운로드한 파일을 themes/ 폴더에 넣고 push하면 자동으로 테마 목록에 추가됩니다.
5. 특정 슬라이드에 적용: frontmatter에 seminar_theme: 테마이름 추가.
